# Protocolo de Rodagem dos Testes Automatizados

A pessoa que rodar o Genesis é responsável por preparar o sistema para a rodagem dos testes gerais. Essa preparação consiste em:

* Obter nome e código da UG principal
* Obter código da UL de estoque
* Definir o intervalo de número patrimonial no cliente
* Colocar ano/mês do Patrimônio e do Almoxarifado no ano/mês atual

## Rodagem dos Testes Gerais

Para aproveitar melhor o tempo, os testes gerais serão divididos entre os integrantes do grupo do time de testes automatizados. Esses são os passos para rodagem dos testes:

* Rode um submódulo por vez (Almoxarifado > Movimentação Interna, Almoxarifado Movimentação Externa, etc.)
* Assim que obtiver o relatório do submódulo gerado pela Sentinela, coloque-o na pasta compartilhada
* Informe como foi a rodagem dos testes; se houve erros na automação, se houve erros no cliente, se teve alguma dificuldade, etc.

Lembrando que chamados de versionamento são sempre urgentes, então eles devem receber toda a nossa atenção e devem ser entregues de volta o mais rápido possível.

# README

Este pequeno projeto foi craido para testar o atendimento simultâneo de requisições.

## Como rodar

Com um terminal aberto na pasta raiz escreva:

`python -m concorrencia.run`

## Onde inserir as informações

As informações sobre o almoxarifado, unidade de requisição e material devem ser inseridas dentro do arquivo `run.py`, que tem uma variável com os dados em formato de dicionário.
